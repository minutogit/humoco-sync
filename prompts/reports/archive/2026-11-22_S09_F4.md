## Verification of Prior Baseline & `f47afd8` Fixes in `F4` Scope

All previously landed `F4`-relevant fixes (`S03`, `S05`, `S06`, `S08`, and `f47afd8`) were audited line-by-line across Rust (`db.rs`, `state.rs`, `web_routes.rs`, `admin_api.rs`, `mailer.rs`, `sync_routes.rs`, `ratelimit.rs`, `crypto.rs`, `config.rs`), PHP (`sync.php`, `config.php`), and `SPEC.md`, and verified intact:
- **Hybrid Mode Isolation (`admin_app` vs `registered`):** `put_admin_members` touches only `ADMIN_MEMBERS` / `ADMIN_MEDIA_CONFIGURED_KEY` and prunes only blobs not authorized by either admin membership or active non-suspended `registered` status (`rust/src/db.rs:1533-1680`); `build_admin_index` excludes `registered`-only users and `media` blobs (`:1682-1728`); `HEAD` returns `200 X-Drop-Authorized: false` without channel/occupancy/ETag leakage (`:917-931`, `sync_routes.rs:281-312`).
- **Free-Pool & Quota Profiles & Grace/Suspended Lifecycle:** `is_free_pool` (`max_free_pool_mb`) isolates free accounts and global Prio-3 eviction evicts `free_pool` media before non-free media while returning `507` rather than allowing `free_pool` uploads to evict paid/friends media (`db.rs:2508-2695`); `downgrade_grace_days` keeps active profile quotas during grace while blocking `?lock_ticket` (`locks.rs:646-648`), drops post-grace effective quota immediately, and clears `encrypted_contact_email` in `run_maintenance` while preserving `email_hmac` (`db.rs:2374-2435`); `Suspended` blocks `PUT`/`lock_ticket`/re-registration (`403`) while enforcing profile-specific media TTLs (`SYNC-S03-10`) and allowing `DELETE ?account`.
- **Web `/register`, `/admin`, `/api/v1/admin/*`, `mailer.rs`:** `store_contact_email = false` omits `contact_email` from confirmation tokens and disk (`web_routes.rs:530-560`, `db.rs:1999-2035`), `/register/confirm` & `/register/delete-confirm` bind strictly to action and `email_hmac`, IPv4 `/24` & IPv6 `/48` (with `::ffff:` normalization via `ratelimit.rs:275-330`) cap open/email registrations, `/admin` enforces Argon2id login + `HttpOnly; SameSite=Strict` (+ `; Secure` case-insensitively on `https://`) + session-bound CSRF + `Cache-Control: no-store` + XSS HTML escaping, `/api/v1/admin/*` enforces Bearer auth (`api_bearer_token_hash` or `admin_token_hash` fallback) + rate limit + bounds (`SYNC-S05-07`), and `mailer.rs` enforces `email.enabled`, CRLF rejection, fail-closed `tls`/`starttls`/`plain`, and bounded timeouts.

## Implemented Safe Fixes

1. **Cluster 1 — Rust `HEAD` `admin_pubkey` `lock` Parity (`rust/src/db.rs`)**
   - `SyncDb::head_capability` (`rust/src/db.rs:914-953`): Compute `is_lock_server_admin = cfg.lock.enabled && !cfg.server.admin_pubkey.is_empty() && pubkey == cfg.server.admin_pubkey`, expose `"lock"` in `allowed_channels`, and evaluate `authorized` against `allowed_channels` both when `access` is `None` and when `access` is `Some` — matching `php/sync.php:1058-1067` and `SPEC.md` §6.5 without granting any non-lock slot permissions.
   - Regression proof (Fail-First verified): `rust/tests/integration_tests.rs:11955-12031` (`test_s09_f4_hybrid_head_pool_grace_suspended_and_codes_parity` panicked at `X-Drop-Authorized` `"false"` != `"true"` before patching `db.rs`) + blackbox parity assertion in `tests/run.sh:1022-1033`.

2. **Cluster 2 — Hoster Benchmark Pass/Fail Gate Tightening (`tests/measure_hoster.sh`)**
   - `tests/measure_hoster.sh:402-405`: Require `HEAD_CODE == "200"`, `DELEGATE_RESULT != FAIL*`, `PROBE_PASS == SAMPLES`, and `RETRY_OK == SAMPLES` (in addition to `ALL_PASSED`, `KEY_LEAK_SAFE`, `RACE_OK`, `RACE_ERR`, `WRITE_OK`, `GET_OK`) before reporting `OVERALL="PASS"`.
   - Regression proof (Fail-First verified): Shell evaluation confirmed unpatched condition produced `OVERALL=PASS` under simulated `HEAD_CODE=403`, `DELEGATE_RESULT="FAIL (403)"`, `PROBE_PASS=0`, `RETRY_OK=0`; local verification passes cleanly on both `--local-rust` and `--local-php`.

3. **Cluster 3 — Cross-Runtime `F4` Blackbox & Rust Integration Blindspot Coverage (`tests/run.sh`, `rust/tests/integration_tests.rs`)**
   - `tests/run.sh:325-335,693-753,843-907,1022-1033`: Added unauthorized oracle-free `HEAD` check on occupied slot server, `backup`-vs-`media` fallback denial (`403`), `PUT ?members&channel=media []` media pruning + `card` preservation across both Rust and PHP, Hybrid `registered` media preservation & `index.json` media exclusion (`deleted_media:1` in `DELETE ?account`), and `HEAD` `admin_pubkey` `X-Channel: lock` parity.
   - `rust/tests/integration_tests.rs:11936-13655`: Added `test_s09_f4_hybrid_head_pool_grace_suspended_and_codes_parity` and `test_s09_f4_web_register_admin_ui_and_admin_api_hardening`.
