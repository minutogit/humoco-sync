## Implemented Safe Fixes

1. **Cluster 1 — Enforce `cfg.lock.max_buckets` on Unseen Bucket Creation in `process_lock_import` & `Finalize` (`rust/src/lock_rotation.rs`)**
   - In `process_lock_import` (`rust/src/lock_rotation.rs:1052-1058`), check `prev_bucket.is_none() && buckets.len()? >= cfg.lock.max_buckets` and return `507 Lock bucket budget exhausted` before clearing or inserting any bucket/inode/rotation/anchor records (preserving rotations on existing buckets at full `max_buckets`).
   - In `process_lock_commit::Finalize` (`rust/src/lock_rotation.rs:1434-1441`), check `existing_bucket.is_none() && buckets.len()? >= cfg.lock.max_buckets` and return `507 Lock bucket budget exhausted` prior to writing `LOCK_ROTATIONS`/`LOCK_ANCHORS`/`LOCK_BUCKETS`/`LOCK_QUARTER_INDEX`.
   - Regression test: `test_s02_import_and_finalize_enforce_max_buckets` (`rust/tests/integration_tests.rs:9116-9490`).

2. **Cluster 2 — Preserve Monotonic `(write_seq, bucket_head)` Across `process_lock_import` on Existing Buckets (`rust/src/lock_rotation.rs`)**
   - In `process_lock_import` (`rust/src/lock_rotation.rs:1079-1123`), map `(slot -> entry_hash)` from `removed_single` when `prev_bucket` exists, seed `(write_seq, bucket_head)` from `(prev_b.write_seq, prev_b.bucket_head)`, and advance `write_seq` + `compute_bucket_step_head` only for `ResolvedSlot::Single` entries whose `(slot, entry_hash)` were not already stored locally (starting from `0` + `compute_bucket_init_head` only when `prev_bucket` is `None`).
   - Regression test: `test_s02_import_preserves_monotonic_head_against_prerotation_receipt` (`rust/tests/integration_tests.rs:9492-9926`).

3. **Cluster 3 — Enforce Linear `migration_chain` Prefix Consistency in `process_lock_import` & `Finalize` (`rust/src/lock_rotation.rs`)**
   - Added `manifests_share_chain_prefix` (`rust/src/lock_rotation.rs:127-141`) verifying that every step `0..existing.migration_chain.len()` matches on `(proposal.core_digest(), imported_state_hash)` when `incoming.revision >= existing.revision`.
   - Enforced `manifests_share_chain_prefix` in `process_lock_import` (`rust/src/lock_rotation.rs:1004-1012`) and unified same-revision / higher-revision checks in `process_lock_commit::Finalize` (`rust/src/lock_rotation.rs:1389-1410`), returning `409 Conflict` on forked histories.
   - Regression test: `test_s02_import_and_finalize_reject_forked_history_chain` (`rust/tests/integration_tests.rs:9928-10375`).
